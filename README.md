# API
I dette prosjektet har jeg laget en enkel webapplikasjon med Python og Flask hvor brukeren kan søke etter informasjon om ulike land.
Nettsiden henter data fra API-er og viser informasjon som:
navn på landet, hovedstad, befolkning, verdensdel og flagg
I tillegg har jeg brukt et ekstra API for å vise været i landet (temperatur og vind). Brukeren kan trykke på en knapp for å se værdata for det valgte landet.
